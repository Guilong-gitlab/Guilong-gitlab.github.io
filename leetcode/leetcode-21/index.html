LeetCode 21：合并两个有序链表

通过双指针和虚拟头节点合并两个升序链表，并学习链表节点连接以及 O(m+n) 复杂度的推导。

2026-10-01
阅读时长: 7 分钟

题目

将两个升序链表合并为一个新的升序链表并返回。新链表由给定两个链表中的所有节点组成。 题目链接：LeetCode 21：合并两个有序链表 难度：简单 例如：

1
2

list1 = 1 → 2 → 4
list2 = 1 → 3 → 4

合并以后：

1

1 → 1 → 2 → 3 → 4 → 4

这道题的关键条件是：两个输入链表本身已经是升序的。 因此每次只需要比较两个链表当前最前面的节点，较小的那个一定可以直接放入结果链表。

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def mergeTwoLists(
        self,
        list1: ListNode | None,
        list2: ListNode | None
    ) -> ListNode | None:
        dummy = ListNode()
        cur = dummy

        while list1 and list2:
            if list1.val <= list2.val:
                cur.next = list1
                list1 = list1.next
            else:
                cur.next = list2
                list2 = list2.next

            cur = cur.next

        cur.next = list1 if list1 else list2

        return dummy.next

我的答案复杂度怎么计算

这次开始重点学习怎么自己计算复杂度。 先定义：

1
2

m = list1 的节点数量
n = list2 的节点数量

例如：

1

list1 = 1 → 2 → 4

有 3 个节点，所以：

1

m = 3

如果：

1

list2 = 1 → 3 → 4 → 7

有 4 个节点，所以：

1

n = 4

先看最主要的循环：

1

while list1 and list2:

循环中每执行一次，一定会发生下面两种情况之一：

1

list1 = list1.next

或者：

1

list2 = list2.next

也就是说，每循环一次，至少有一个链表向后移动一个节点。 两个链表总共只有：

1

m + n

个节点。 所以程序不可能无限循环，最多只会处理这些节点。 因此循环执行次数的数量级是：

1

m + n

循环里面：

1

if list1.val <= list2.val:

只是一次比较，可以看成：

1

O(1)

下面这些操作：

1
2
3

cur.next = list1
list1 = list1.next
cur = cur.next

每一个也都只是修改一次指向，可以看成：

1

O(1)

因此可以理解成：

1
2
3

最多处理 m+n 个节点
×
每个节点只需要常数次操作

所以：

1
2

O(m+n) × O(1)
= O(m+n)

因此我的答案时间复杂度为：

1

O(m+n)

这里非常重要： 不是 O(m×n)。 因为代码并没有：

1
2

for list1:
    for list2:

这样的嵌套遍历。 两个链表只是一起从左向右移动：

1
2

list1 → → → →
list2 → → → →

所以是：

1

m + n

而不是：

1

m × n

再看空间复杂度。 程序额外创建了：

1
2

dummy = ListNode()
cur = dummy

还有：

1
2

list1
list2

这些变量的数量不会随着 m、n 增大而不断增加。 无论链表有：

1
2
3

10 个节点
100 个节点
100000 个节点

我们额外使用的主要变量始终只有几个。 而且：

1

cur.next = list1

并没有复制 list1 的所有节点，而是直接把已有节点连接起来。 因此额外空间复杂度为：

1

O(1)

所以我的答案：

1
2

时间复杂度：O(m+n)
空间复杂度：O(1)

关键知识点

这道题首先要掌握链表最基本的两个操作。 沿链表向后移动：

1

node = node.next

修改链表连接：

1

node.next = another_node

这两句话一定要区分。 例如：

1

list1 = list1.next

是：

1

移动 list1

而：

1

cur.next = list1

是：

1

把 cur 后面连接到 list1

第二个重要知识是虚拟头节点：

1
2

dummy = ListNode()
cur = dummy

它可以避免对结果链表的第一个节点进行特殊处理。 最后返回：

1

dummy.next

而不是：

1

dummy

第三个重要知识是两个有序序列合并时的思路：

1
2
3
4
5
6
7

比较两个当前位置
        ↓
选择较小的
        ↓
较小的一边向后移动
        ↓
继续比较

这种思想以后还会大量出现。 第四个知识是这次复杂度计算的核心：

1
2
3
4
5
6
7
8

一个链表 m 个节点
另一个链表 n 个节点

两个链表各自最多完整走一遍

m + n
↓
O(m+n)

如果以后看到：

1
2
3

两个长度分别为 m、n 的数据结构
分别向前走
每个元素最多处理一次

就应该开始考虑：

1

O(m+n)

而如果是：

1
2

对第一个数据结构的每个元素
    都完整遍历第二个数据结构

才通常是：

1
2
3

m × n
↓
O(mn)
