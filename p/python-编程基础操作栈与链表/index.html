栈（Stack）

栈（Stack）是一种**后进先出（Last In, First Out，LIFO）**的数据结构。

可以把它理解成一摞盘子：只能从最上面放，也只能从最上面取。因此最后放进去的元素会最先被取出来。

例如依次放入 1、2、3：

1
2
3
4

| 3 | ← 栈顶
| 2 |
| 1 |
-----

取出时：

1

3 → 2 → 1

Python 中一般不需要专门定义 Stack，刷题时直接使用 list：

1

stack = []

也可以创建一个已经有元素的栈：

1

stack = [1, 2, 3]

此时列表的最后一个位置作为栈顶：

1
2
3

[1, 2, 3]
       ↑
      栈顶

栈最重要的不是 append() 和 pop() 本身，而是理解：

什么东西应该放进栈里？

一个很常见的判断方法是：

当前遇到一个东西，现在还不能处理完，需要暂时保存；之后处理时，又应该优先处理最近保存的那个东西。

这种情况往往适合使用栈。

使用 Python list 作为栈时，常见操作为：

操作Python含义时间复杂度

入栈stack.append(x)放入栈顶均摊 $O(1)$

判断为空if stack判断是否有元素$O(1)$

链表（Linked List）

链表（Linked List）和 Python 普通列表的结构完全不同。

普通列表看起来是：

1

nums = [10, 20, 30, 40]

而单链表可以理解成：

1

10 → 20 → 30 → 40 → None

链表由一个个**节点（Node）**组成。

每个节点至少保存两个东西：

1
2

val   → 当前节点的数据
next  → 下一个节点

因此 LeetCode 中最常见的链表节点定义是：

1
2
3
4

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

1

1

1
