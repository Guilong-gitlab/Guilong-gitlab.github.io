LeetCode 13：罗马数字转整数

使用字典建立罗马字符与整数的映射，并通过比较相邻字符将罗马数字转换为整数。

2026-09-29
阅读时长: 5 分钟

题目

罗马数字包含以下七种字符：

字符数值
I1
V5
X10
L50
C100
D500
M1000

例如：

1
2
3

II     = 1 + 1 = 2
XII    = 10 + 1 + 1 = 12
XXVII  = 10 + 10 + 5 + 1 + 1 = 27

通常情况下，罗马数字中较小的数字位于较大数字的右边，此时直接相加即可。

但是存在六种特殊情况：

1
2
3
4
5
6

IV = 4
IX = 9
XL = 40
XC = 90
CD = 400
CM = 900

这些特殊情况具有相同的规律：

如果一个较小的数字出现在较大数字左边，那么应该用右边的大数减去左边的小数。

给定一个罗马数字，将其转换成整数。

题目链接：LeetCode 13：罗马数字转整数

难度：简单

class Solution:
    symbol_value = {
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000,
    }

    def romanToInt(self, s: str) -> int:
        num = len(s)
        ans = 0

        for i in range(num - 1):
            value = Solution.symbol_value[s[i]]
            value_next = Solution.symbol_value[s[i + 1]]

            if value < value_next:
                ans -= value
            else:
                ans += value

        return ans + Solution.symbol_value[s[-1]]

这个思路是正确的，而且已经是这道题非常标准的一种解法。

class Solution:
    symbol_value = {
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000
    }

    def romanToInt(self, s: str) -> int:
        n = len(s)
        ans = 0

        for i in range(n - 1):
            value = Solution.symbol_value[s[i]]
            next_value = Solution.symbol_value[s[i + 1]]

            if value < next_value:
                ans -= value
            else:
                ans += value

        ans += Solution.symbol_value[s[-1]]

        return ans

写：

因此，当题目中存在这种：

1

的关系时，字典通常是非常方便的数据结构。

程序中：

1

为什么只循环到 n - 1？

因为循环中不仅需要访问：

1

还需要访问：

1

也就是下一个字符。

1

1

1

1

就会变成：

1

s[3]

但是字符串最后一个合法下标只有：

1

2

因此程序会发生下标越界。

所以这里只处理到倒数第二个字符：

1

1

class Solution:
    def romanToInt(self, s: str) -> int:
        symbol_value = {
            'I': 1,
            'V': 5,
            'X': 10,
            'L': 50,
            'C': 100,
            'D': 500,
            'M': 1000
        }

        ans = 0

        for i in range(len(s) - 1):
            if symbol_value[s[i]] < symbol_value[s[i + 1]]:
                ans -= symbol_value[s[i]]
            else:
                ans += symbol_value[s[i]]

        ans += symbol_value[s[-1]]

        return ans

这样就可以直接使用：

1

symbol_value[s[i]]

而不需要：

1

Solution.symbol_value[s[i]]

这是因为原来的 symbol_value 写在：

1

class Solution:

下面，所以它属于 Solution 类。

现阶段不需要深入理解 Python 的类和对象，只需要知道：

如果字典定义在函数里面：

1
2

def romanToInt(...):
    symbol_value = {...}

直接使用：

1

symbol_value[...]

即可。

复杂度

假设罗马数字字符串长度为 n。

程序从左向右遍历一次字符串，所以时间复杂度为：

1

O(n)

也就是说，如果字符串长度增加一倍，需要检查的字符数量大约也增加一倍。

字典中始终只有七个字符：

1

I V X L C D M

它不会随着输入长度增加，因此额外空间复杂度可以认为是：

1

O(1)

一句话总结：

罗马数字转整数的关键是用字典建立字符与数值的对应关系，并发现统一规律：当前数字小于右边数字时做减法，否则做加法。
