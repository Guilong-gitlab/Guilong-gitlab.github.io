LeetCode 9：回文数

使用左右对称比较、字符串反转和数学方法判断一个整数是否为回文数。

2026-09-29
阅读时长: 3 分钟

题目

给你一个整数 x，如果 x 是一个回文整数，返回 True，否则返回 False。

回文数就是从左往右读和从右往左读完全一样的整数。

题目链接：LeetCode 9：回文数

难度：简单

示例：

1
2
3

121   →  121   → True
123   →  321   → False
-121  →  121-  → False

我的思路

我的原始思路是先把整数转换成字符串，然后比较字符串左右两侧的对称字符：

  1. 使用 str(x) 把整数转换成字符串。
  2. 使用 len(s) 得到字符串长度。
  3. 从字符串左侧开始遍历。
  4. 比较左边第 i 个字符和右边对应位置的字符。
  5. 只要发现一组字符不同，就立即返回 False。
  6. 如果所有对称位置都相同，就返回 True。

原代码中的 flag = 0 没有被使用，可以删除。

另外，原来的 range(n) 会把相同位置重复比较。例如：

1
2

字符： 1  2  3  2  1
下标： 0  1  2  3  4

实际上只需要比较：

1
2

0 ↔ 4
1 ↔ 3

因此只遍历字符串的一半即可：range(n // 2)。

推荐解法：比较左右对称字符

class Solution:
    def isPalindrome(self, x: int) -> bool:
        s = str(x)
        n = len(s)

        for i in range(n // 2):
            if s[i] != s[n - i - 1]:
                return False

        return True

长度为 n 的字符串最后一个下标是 n - 1，所以位置 i 在右侧的对称位置就是：

1

n - i - 1

例如 n = 5 时：

1
2

i = 0  →  5 - 0 - 1 = 4
i = 1  →  5 - 1 - 1 = 3

return False 可以放在循环内部，因为发现一组字符不相同后，就已经可以确定它不是回文数。return True 必须放在循环结束之后，表示所有对称位置都检查通过。

Python 简洁写法

1
2
3
4

class Solution:
    def isPalindrome(self, x: int) -> bool:
        s = str(x)
        return s == s[::-1]

s[::-1] 表示把字符串反转：

1
2

s = "123"
s[::-1]  # "321"

这种写法很简洁，但练习阶段更建议先掌握左右比较的过程，理解回文问题的核心逻辑。

不使用字符串的数学解法

也可以通过取出每一位数字的方式反转整数：

class Solution:
    def isPalindrome(self, x: int) -> bool:
        if x < 0:
            return False

        original = x
        reversed_num = 0

        while x > 0:
            digit = x % 10
            reversed_num = reversed_num * 10 + digit
            x //= 10

        return original == reversed_num

这里有两个重要操作：

1
2

x % 10   # 取得最后一位，例如 123 % 10 == 3
x // 10  # 去掉最后一位，例如 123 // 10 == 12

以 123 为例：

1
2
3

x = 123，取出 3，reversed_num = 3，x = 12
x = 12，取出 2，reversed_num = 32，x = 1
x = 1，取出 1，reversed_num = 321，x = 0

最后比较原数字和反转后的数字是否相同。

复杂度

假设整数有 n 位：

  • 字符串比较的时间复杂度：O(n)。
  • 字符串方法的额外空间复杂度：O(n)。
  • 数学方法的额外空间复杂度：O(1)。

时间复杂度表示程序需要进行多少计算，空间复杂度表示运行时额外需要多少存储空间。

关键知识点

  1. str(x) 可以把整数转换成字符串。
  2. len(s) 可以获得字符串长度。
  3. Python 的下标从 0 开始。
  4. 长度为 n 的字符串最后一个位置是 n - 1。
  5. 位置 i 的左右对称位置是 n - i - 1。
  6. 回文问题可以从左右两端同时比较。
  7. 发现不相等时可以立即返回 False。
  8. x % 10 可以取得正整数的最后一位。
  9. x // 10 可以去掉正整数的最后一位。

复盘

这道题的核心不是背下完整代码，而是理解左右对称关系：

1

左端  →  →  →  中间  ←  ←  ←  右端

class Solution:
    def isPalindrome(self, x: int) -> bool:
        s = str(x)
        n = len(s)

        for i in range(n // 2):
            if s[i] != s[n - i - 1]:
                return False

        return True
