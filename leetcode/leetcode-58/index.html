LeetCode 58：最后一个单词的长度

通过从后向前遍历字符串寻找最后一个单词，并理解顺序遍历、嵌套循环与 O(n) 时间复杂度的区别。

class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        l = len(s) - 1

        for i in range(l, -1, -1):
            if s[i] != ' ':
                for j in range(i, -1, -1):
                    if s[j] == ' ':
                        return i - j
                    elif j == 0:
                        return i + 1

class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        i = len(s) - 1

        while s[i] == ' ':
            i -= 1

        length = 0

        while i >= 0 and s[i] != ' ':
            length += 1
            i -= 1

        return length

关键知识点

这道题首先要学会反向遍历。 普通遍历：

1

for i in range(len(s)):

得到：

1

0,1,2,3,...,n-1

反向遍历：

1

for i in range(len(s) - 1, -1, -1):

得到：

1

n-1,n-2,...,2,1,0

range() 的三个参数：

1

range(start, stop, step)

所以：

1

range(len(s) - 1, -1, -1)

表示：

1
2
3

start = len(s)-1   从最后一个下标开始
stop  = -1         到 -1 前停止，因此包含 0
step  = -1         每次减 1

两个循环不一定是 O(n²)

O(n) + O(n)
→ O(n)

真正嵌套，并且每次都完整执行：
O(n) × O(n)

一句话总结： 寻找字符串最后一个单词时，可以直接从字符串末尾向前扫描，先跳过末尾空格，再统计连续非空格字符的数量；整个过程中每个相关字符最多被扫描一次，因此时间复杂度为 O(n)，额外空间复杂度为 O(1)。
