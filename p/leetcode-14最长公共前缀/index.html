LeetCode 14：最长公共前缀

通过字符串切片和逐列比较的方法，查找字符串数组中的最长公共前缀。

2026-09-30

题目

编写一个函数来查找字符串数组中的最长公共前缀。 如果不存在公共前缀，返回空字符串 ""。 题目链接：LeetCode 14：最长公共前缀 难度：简单 示例 1：

class Solution:
    def longestCommonPrefix(self, strs: list[str]) -> str:
        min_len = 200
        flag = True
        for single_str in strs:
            if len(single_str) < min_len:
                min_len = len(single_str)
                min_str = single_str

        for length in range(min_len, -1, -1):
            for i in range(len(strs)):
                if strs[i][:length] != min_str[:length]:
                    flag = False
                    break
            if flag:
                break
            flag = True

        return min_str[:length]

推荐解法：纵向比较

你的方法可以正确解决问题，不过这道题还有一种更直接的标准思路：从第一个字符开始，一列一列比较所有字符串。 例如：

全部相同，所以目前公共前缀是：

1

o
i

发现不同。 那么后面已经不用继续比较了，因为公共前缀到这里已经结束。 最终答案：

1

class Solution:
    def longestCommonPrefix(self, strs: list[str]) -> str:
        for i in range(len(strs[0])):
            char = strs[0][i]

            for j in range(1, len(strs)):
                if i == len(strs[j]) or strs[j][i] != char:
                    return strs[0][:i]

        return strs[0]

复杂度

假设：

1
2

字符串数量 = n
最短字符串长度 = m

无论使用你的方法还是纵向比较方法，都需要比较多个字符串中的字符。 纵向比较的时间复杂度可以理解为：

1

O(n × m)

也就是说，最坏情况下需要检查每个字符串的前 m 个字符。 除了几个变量以外，没有创建很大的额外数据结构，所以额外空间复杂度为：

1

O(1)

现阶段重点不是背这个公式，而是理解：

1
2

字符串越多 → 要比较的次数越多
字符串越长 → 可能要比较的位置越多

所以两者都会影响运行时间。

class Solution:
    def longestCommonPrefix(self, strs: list[str]) -> str:
        for i in range(len(strs[0])):
            char = strs[0][i]

            for j in range(1, len(strs)):
