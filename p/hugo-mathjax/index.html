Hugo 建站（三）：用 MathJax 实现公式编号与引用

在 Stack 主题中按文章启用 MathJax 3，并设置公式编号、标签和交叉引用。

2025-02-26
阅读时长: 3 分钟

需要在博客中使用 \label、\eqref 和自动编号时，可以使用 MathJax。本文以本站包含的 Stack 模板结构和 MathJax 3 为例；下面是配置步骤，只有完成模板接入后才会渲染公式。

1. 避免同时启用两套公式渲染器

本站的 Stack 主题通过 math 参数加载 KaTeX。使用本文方案的文章保留 math: false，另设 mathjax: true，由自定义模板决定是否加载 MathJax。两套渲染器不要同时处理同一篇正文。

2. 使用主题提供的自定义入口

在站点根目录新建 layouts/partials/head/custom.html。本站主题的 head/head.html 已经调用这个入口，不需要复制整份 HTML 文档，也不要在 partial 中重新写 <html>、<head> 或 <body>。

写入以下内容；若该文件已有其他设置，将代码合并进去：

{{ if .Params.mathjax }}
<script>
  window.MathJax = {
    tex: {
      tags: 'ams',
      inlineMath: [['\\(', '\\)']],
      displayMath: [['$$', '$$'], ['\\[', '\\]']]
    }
  };
</script>
<script defer src="https://cdn.jsdelivr.net/npm/mathjax@3.2.2/es5/tex-chtml.js"></script>
{{ end }}

tags: 'ams' 为 equation 等可编号环境生成编号；equation* 不编号。若希望普通显示公式也自动编号，可以改成 tags: 'all'。MathJax 公式编号文档 说明了两者的区别。

3. 让 Markdown 保留公式内容

在 hugo.yaml 的现有 markup.goldmark 下合并以下设置，不要再创建第二个 markup 键：

markup:
  goldmark:
    extensions:
      passthrough:
        enable: true
        delimiters:
          block:
            - ['\[', '\]']
            - ['$$', '$$']
          inline:
            - ['\(', '\)']

上面 YAML 单引号字符串中的分隔符各含一个反斜杠，即 '\['、'\]'、'\('、'\)'。JavaScript 字符串中的反斜杠需要写成两个反斜杠 \\。本站已有 passthrough 配置，使用时检查现有设置即可。

4. 在文章中写公式

为使用 MathJax 的文章添加：

math: false
mathjax: true

正文写成下面这样。这里用代码块展示源码；复制到自己的文章时，公式本身不要放在代码围栏内：

$$
\begin{equation}
E = mc^2
\label{eq:energy}
\end{equation}
$$

质量与能量的关系见公式 \eqref{eq:energy}。

行内变量可以写成 \(m\) 和 \(c\)。

\label{eq:energy} 为公式命名，\eqref{eq:energy} 输出带括号的编号。每个标签在同一页面中必须唯一，普通链接的锚点与公式标签是两套机制。

5. 检查与排错

  1. 运行 hugo server，查看目标文章，而不是编辑器预览。
  2. 查看页面源码，确认出现 MathJax 配置和脚本标签。
  3. 若一直显示 TeX 源码，检查浏览器网络面板中 CDN 是否加载成功。
  4. 若反斜杠或下划线被改变，检查 passthrough 和公式分隔符。
  5. 若重复排版或样式冲突，检查该文章是否还启用了 KaTeX。
  6. 若编号显示 ??，检查标签拼写、重复标签及公式语法。

只有设置 mathjax: true 的文章会加载这个脚本，普通文章不需要额外下载公式渲染器。Stack 自定义入口说明见 Custom Header / Footer。
