Isaac 路线

  • Isaac Lab：G1 基础场景：理解应用启动、场景配置与机器人加载。
  • G1 Isaac Nav：定位与导航：使用 Isaac Sim、ROS 2 Humble、RTAB-Map 和 Nav2 建立导航链。

MuJoCo 教程的主分支使用 Jazzy 容器，Isaac Nav 教程使用 Ubuntu 22.04 / Humble。两条路线应分别准备环境，不需要按文章顺序把所有软件装入同一个 Python 环境。
