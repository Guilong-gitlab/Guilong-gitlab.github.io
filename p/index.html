LeetCode 13 - 罗马数字转整数

难度：简单

给定一个罗马数字字符串 s，将它转换成整数。

罗马数字有 7 个基本字符：

字符    数值
I       1
V       5
X       10
L       50
C       100
D       500
M       1000

例如：

II     = 1 + 1 = 2
XII    = 10 + 1 + 1 = 12
XXVII  = 10 + 10 + 5 + 1 + 1 = 27

正常情况下，罗马数字从左向右，较大的数字放在前面，所以直接相加即可。

但是存在 6 种特殊情况：

IV = 4
IX = 9
XL = 40
XC = 90
CD = 400
CM = 900

这些情况的共同特点是：

左边的数字比右边的数字小。

例如：

IV

其中：

I = 1
V = 5

因为：

1 < 5

所以不能计算：

1 + 5 = 6

而应该计算：

5 - 1 = 4

我的思路

我的代码：

class Solution:
    symbol_value = {
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000,
    }

    def romanToInt(self, s: str) -> int:
        num = len(s)
        ans = 0

        for i in range(num - 1):
            value = Solution.symbol_value[s[i]]
            value_next = Solution.symbol_value[s[i + 1]]

            if value < value_next:
                ans -= value
            else:
                ans += value

        return ans + Solution.symbol_value[s[-1]]

这个答案是正确的，而且已经是这道题非常标准的一种解法。

整个程序的核心思想只有一句话：

如果当前罗马数字比后面的罗马数字小，就减去当前值；否则就加上当前值。

例如：

III

每个数字都没有比右边的小，所以：

1 + 1 + 1 = 3

例如：

VI

因为：

V > I

所以：

5 + 1 = 6

例如：

IV

因为：

I < V

所以：

-1 + 5 = 4

因此，不需要专门判断：

IV
IX
XL
XC
CD
CM

只需要判断：

当前值 < 下一个值

就可以统一处理所有特殊情况。

这个地方是这道题最重要的算法思想。

关键知识点

这道题首先需要掌握一个新的 Python 数据结构：

字典（dictionary，简称 dict）

代码：

symbol_value = {
    'I': 1,
    'V': 5,
    'X': 10,
    'L': 50,
    'C': 100,
    'D': 500,
    'M': 1000,
}

字典可以理解成一种：

名字 → 对应的值

例如：

'I' → 1
'V' → 5
'X' → 10

所以可以通过：

symbol_value['I']

得到：

1

通过：

symbol_value['X']

得到：

10

这非常适合本题，因为罗马字符和整数之间正好存在固定的对应关系。

以后遇到这种问题：

A 对应某个值
B 对应某个值
C 对应某个值

通常就可以考虑使用字典。

你的程序中：

num = len(s)

表示获得字符串长度。

例如：

s = "XIV"

那么：

num = 3

字符串的下标为：

字符： X  I  V
下标： 0  1  2

然后：

for i in range(num - 1):

这里为什么不是：

range(num)

这是因为循环里面需要访问：

s[i + 1]

也就是当前字符的下一个字符。

如果一直循环到最后一个字符：

i = num - 1

那么：

i + 1 = num

就会访问：

s[num]

但是长度为 num 的字符串，最后一个合法下标是：

num - 1

所以：

s[num]

超出了字符串范围，会报错。

因此这里只循环到倒数第二个字符：

range(num - 1)

最后一个字符再单独处理。

下面这两句：

value = Solution.symbol_value[s[i]]
value_next = Solution.symbol_value[s[i + 1]]

分别表示：

value      = 当前罗马字符对应的整数
value_next = 下一个罗马字符对应的整数

例如：

s = "IV"

第一次循环：

i = 0

那么：

s[i] = 'I'
s[i+1] = 'V'

通过字典：

value = 1
value_next = 5

然后判断：

if value < value_next:

也就是：

if 1 < 5:

条件成立，所以：

ans -= value

相当于：

ans = ans - 1

因此：

ans = -1

循环结束以后执行：

return ans + Solution.symbol_value[s[-1]]

这里又出现了：

s[-1]

Python 中：

s[-1]

表示字符串的最后一个字符。

例如：

s = "XIV"

那么：

s[-1] = 'V'

所以对于 IV：

ans = -1

最后加上：

V = 5

得到：

-1 + 5 = 4

我们再完整运行一个稍微复杂一点的例子：

s = "MCMXCIV"

对应：

M    C    M    X    C    I    V
1000 100  1000 10   100  1    5

第一次：

M 和 C

因为：

1000 > 100

所以：

ans = 1000

第二次：

C 和 M

因为：

100 < 1000

所以：

ans = 1000 - 100
    = 900

第三次：

M 和 X

因为：

1000 > 10

所以：

ans = 900 + 1000
    = 1900

第四次：

X 和 C

因为：

10 < 100

所以：

ans = 1900 - 10
    = 1890

第五次：

C 和 I

因为：

100 > 1

所以：

ans = 1890 + 100
    = 1990

第六次：

I 和 V

因为：

1 < 5

所以：

ans = 1990 - 1
    = 1989

最后一个字符：

V = 5

所以：

ans = 1989 + 5
    = 1994

最终：

MCMXCIV = 1994

推荐答案

你的代码已经完全可以作为标准答案。

稍微调整一下写法：

class Solution:
    symbol_value = {
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000
    }

    def romanToInt(self, s: str) -> int:
        ans = 0
        n = len(s)

        for i in range(n - 1):
            value = Solution.symbol_value[s[i]]
            next_value = Solution.symbol_value[s[i + 1]]

            if value < next_value:
                ans -= value
            else:
                ans += value

        ans += Solution.symbol_value[s[-1]]

        return ans

这里我把：

value_next

改成：

next_value

只是个人习惯，两种写法都没有问题。

另外把：

return ans + Solution.symbol_value[s[-1]]

拆成：

ans += Solution.symbol_value[s[-1]]
return ans

对于初学阶段来说，这样更容易看清楚：

先处理最后一个数字，然后返回最终结果。

当然，你原来的写法完全正确。

还有一种写法，是把字典放到函数里面：

class Solution:
    def romanToInt(self, s: str) -> int:
        symbol_value = {
            'I': 1,
            'V': 5,
            'X': 10,
            'L': 50,
            'C': 100,
            'D': 500,
            'M': 1000
        }

        ans = 0

        for i in range(len(s) - 1):
            if symbol_value[s[i]] < symbol_value[s[i + 1]]:
                ans -= symbol_value[s[i]]
            else:
                ans += symbol_value[s[i]]

        ans += symbol_value[s[-1]]

        return ans

这样就可以直接写：

symbol_value[s[i]]

而不需要：

Solution.symbol_value[s[i]]

现阶段这两种方式都可以。

不过这里顺便要理解为什么你的代码需要写：

Solution.symbol_value

因为你把：

symbol_value

定义在了：

class Solution:

里面，而不是：

romanToInt()

函数里面。

所以它属于 Solution 类。

因此可以通过：

Solution.symbol_value

访问。

关于“类”和“对象”现在不需要深入学习，后面遇到相关题目时再系统讲。

复杂度

假设罗马数字字符串长度为 n。

程序需要从左到右遍历一次：

for i in range(n - 1):

所以时间复杂度是：

O(n)

字典只有固定的 7 个罗马字符：

I V X L C D M

不会随着输入字符串长度增加，因此额外空间可以认为是：

O(1)

现阶段可以简单理解为：

字符串有多长，程序基本就检查多少次，所以是 O(n)。

这道题要记住什么

这道题不要背具体的 IV、IX、XL、XC、CD、CM 六个判断。

真正应该记住的是：

观察特殊情况的共同规律。

这六种情况：

IV
IX
XL
XC
CD
CM

虽然看起来有六种，但它们都有同一个规律：

左边数字 < 右边数字

所以可以统一变成：

if 当前值 < 下一个值:
    减去当前值
else:
    加上当前值

这就是写算法时非常重要的一种思维：

不要分别处理很多特殊情况，而是尝试寻找这些特殊情况背后的共同规律。

另外需要记住几个 Python 基础：

  1. 字典适合保存“某个东西对应某个值”的关系。

例如：

'I' → 1
'V' → 5
'X' → 10

  1. 字典取值：

    symbol_value[‘I’]

得到：

1

  1. s[i] 表示当前位置。

  2. s[i+1] 表示下一个位置。

  3. 如果程序中使用了 s[i+1]，就要特别注意最后一个位置是否会发生下标越界。

  4. s[-1] 表示字符串最后一个字符。

  5. ans += value 等价于：

    ans = ans + value

  6. ans -= value 等价于：

    ans = ans - value

本题最值得记住的代码结构是：

for i in range(n - 1):

    if 当前值 < 下一个值:
        ans -= 当前值
    else:
        ans += 当前值

ans += 最后一个值

return ans

一句话总结：

罗马数字转整数的关键不是记住六种特殊组合，而是发现统一规律：如果当前数字比右边的数字小，就减去当前数字，否则就加上当前数字。
