LeetCode 27：移除元素

使用快慢指针原地移除数组中的指定元素，并理解 Python 列表引用以及 O(n) 时间复杂度和 O(1) 空间复杂度。

2026-10-02
阅读时长: 6 分钟

题目

给定一个数组 nums 和一个值 val，原地移除所有数值等于 val 的元素，并返回 nums 中与 val 不同的元素数量。 假设不等于 val 的元素数量为 k，处理以后只要求：

1

nums 的前 k 个元素都是不等于 val 的元素

至于：

1

nums[k:]

val = 3

1

所以：

1

k = 2

只需要保证处理以后：

1

nums = [2,2,...]
         ↑ ↑
       前k个

然后返回：

1

2

class Solution:
    def removeElement(self, nums: list[int], val: int) -> int:
        n = len(nums)
        j = 0
        new_nums = nums

        for i in range(n):
            if nums[i] != val:
                new_nums[j] = nums[i]
                j += 1

        return j

这个答案是正确的，而且本质上已经是这道题的标准快慢指针解法。 我的思路实际上是：

1
2

i：负责检查原数组中的每个元素
j：记录下一个有效元素应该放在哪里

当：

1

nums[i] != val

说明当前元素应该保留，于是：

1

new_nums[j] = nums[i]

把这个有效元素放到数组前面，然后：

1

j += 1

让 j 指向下一个可以存放有效元素的位置。 如果：

1

nums[i] == val

什么都不做，i 继续向后检查。 这样所有不等于 val 的元素就会逐渐被写到数组前面。

new_nums = nums 到底做了什么

这里非常值得注意：

1

new_nums = nums

并没有创建一个新的数组。 假设：

1
2

nums = [1, 2, 3]
new_nums = nums

可以把它理解成：

1
2
3
4
5

nums ───────┐
            ↓
          [1,2,3]
            ↑
new_nums ───┘

nums 和 new_nums 指向的是同一个列表。 所以执行：

1

new_nums[0] = 100

以后：

1

nums

也会变成：

1

[100,2,3]

例如：

1
2
3
4
5
6

new_nums = nums

new_nums[0] = 100

结果：

1

[100, 2, 3]

因此你的代码确实是在修改原来的：

1

nums

符合这道题“原地修改”的要求。 这一点和下面的写法完全不同：

1

new_nums = nums.copy()

或者：

1

new_nums = nums[:]

这两种写法才会真正创建一个新的列表：

1
2
3

nums     → [1,2,3]

new_nums → [1,2,3]

这时修改 new_nums 就不会修改 nums。 所以你的：

1

new_nums = nums

不会产生一个长度为 n 的新数组，额外空间不是 O(n)。 不过这里其实完全没有必要增加 new_nums 这个变量。 直接修改：

1

nums[j] = nums[i]

会更加清楚。

n 次
