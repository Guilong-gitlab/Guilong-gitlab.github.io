宇树开源项目导读与 Python SDK 入门

区分模型、通信 SDK、仿真与强化学习仓库，并梳理 Python SDK 的安装与示例。

2025-07-04
阅读时长: 6 分钟

本文整理原笔记涉及的仓库和 Python SDK 示例。仓库支持范围会随版本变化，名称后的 -main、-master 通常来自下载压缩包后的文件夹名，不是 Python 包名。请同时记录所用提交号。

开源仓库按用途分类

本文主要围绕 Go2 与 G1 学习。先按要解决的问题选择仓库，再阅读目标型号的示例。

用途原笔记涉及的仓库阅读重点
控制算法学习unitree_guide建模、关节控制与足式机器人控制
模仿学习unitree_IL_lerobot数据、策略与硬件接口的连接
MuJoCo 仿真unitree_mujoco模型、仿真循环与 SDK 通信
强化学习unitree_rl_gym、unitree_rl_lab训练环境、观测、动作与策略部署
ROS 接入unitree_ros、unitree_ros2区分 ROS 版本、模型描述与通信接口
C++ / Python 通信unitree_sdk2、unitree_sdk2_python消息、客户端、状态与控制示例
相机接口UnitreecameraSDK对照支持的设备型号，不直接套用到其他机器人

机器人型号、固件和仓库版本共同决定接口能否使用。仓库名称相近，不意味着脚本可以互换。与 G1 仿真有关的场景和导航内容可从 阅读导航 继续。

FAQ

找不到 Cyclone DDS

Could not locate cyclonedds. Try to set CYCLONEDDS_HOME or CMAKE_PREFIX_PATH

该错误提示找不到 cyclonedds 路径。首先编译安装cyclonedds：

1
2
3
4
5

cd ~
git clone https://github.com/eclipse-cyclonedds/cyclonedds -b releases/0.10.x 
cd cyclonedds && mkdir build install && cd build
cmake .. -DCMAKE_INSTALL_PREFIX=../install
cmake --build . --target install

进入 unitree_sdk2_python 目录，设置 CYCLONEDDS_HOME 为刚刚编译好的 cyclonedds 所在路径，再安装 unitree_sdk2_python

1
2
3
4

cd ~/unitree_sdk2_python
source .venv/bin/activate
export CYCLONEDDS_HOME="$HOME/cyclonedds/install"
python -m pip install -e .

详细见： https://pypi.org/project/cyclonedds/#installing-with-pre-built-binaries

使用

以下示例路径来自原笔记版本，运行前先检查当前仓库 example/ 的实际结构与型号目录。每个新终端都应进入 SDK 根目录并激活 .venv。部分控制、避障与灯光示例面向四足机器人，不是 G1 的通用功能。

python sdk2 接口与 unitree_sdk2的接口保持一致，通过请求响应或订阅发布topic实现机器人的状态获取和控制。相应的例程位于/example目录下。在运行例程前，需要根据文档 https://support.unitree.com/home/zh/developer/Quick_start 配置好机器人的网络连接。

DDS通讯

在终端中执行：

1

python3 ./example/helloworld/publisher.py

打开新的终端，执行：

1

python3 ./example/helloworld/subscriber.py

可以看到终端输出的数据信息。publisher.py 和 subscriber.py 传输的数据定义在 user_data.py 中，用户可以根据需要自行定义需要传输的数据结构。

高层状态和控制

高层接口的数据结构和控制方式与unitree_sdk2一致。具体可见：https://support.unitree.com/home/zh/developer/sports_services

高层状态

终端中执行：

1

python3 ./example/high_level/read_highstate.py enp2s0

其中 enp2s0 为机器人所连接的网卡名称，请根据实际情况修改。

底层状态和控制

底层接口的数据结构和控制方式与unitree_sdk2一致。具体可见：https://support.unitree.com/home/zh/developer/Basic_services

底层示例中的状态读取

终端中执行：

1

python3 ./example/low_level/lowlevel_control.py enp2s0

其中 enp2s0 为机器人所连接的网卡名称，请根据实际情况修改。原笔记中的示例还会输出关节、IMU 和电池状态，但 lowlevel_control.py 同时包含控制逻辑，不能把它当作只读程序。

底层电机控制

首先使用 app 关闭高层运动服务(sport_mode)，否则会导致指令冲突。 终端中执行：

1

python3 ./example/low_level/lowlevel_control.py enp2s0

其中 enp2s0 为机器人所连接的网卡名称，请根据实际情况修改。左后腿 hip 关节会保持在0角度 (安全起见，这里设置 kp=10, kd=1)，左后腿 calf 关节将持续输出 1Nm 的转矩。

遥控器状态获取

终端中执行：

1

其中 enp2s0 为机器人所连接的网卡名称，请根据实际情况修改。 终端将输出每一个按键的状态。对于遥控器按键的定义和数据结构可见： https://support.unitree.com/home/zh/developer/Get_remote_control_status

其中 enp2s0 为机器人所连接的网卡名称，请根据实际情况修改。

其中 enp2s0 为机器人所连接的网卡名称，请根据实际情况修改。机器人将循环开启和关闭避障功能。关于避障服务，详细见 https://support.unitree.com/home/zh/developer/ObstaclesAvoidClient

# 从setuptools模块导入必要的函数, setup: 用于配置和创建Python包的主函数，find_packages: 自动发现目录中Python包的辅助函数
from setuptools import setup, find_packages 

# 调用setup函数定义包配置
setup(
      # 必需参数: 包名称（用于pip安装）
      name='unitree_sdk2py', 

      # 必需参数: 包版本号（遵循语义化版本规范）
      version='1.0.1', 

      # 必需参数: 包含在分发包中的Python包列表，find_packages()自动发现包，'include'参数限制只包含指定的包名
      packages=find_packages(include=['unitree_sdk2py','unitree_sdk2py.*']), 

      # 可选参数: 作者名称（个人或组织）
      author='UnitreeRobotics', 

      # 可选参数: 作者联系邮箱
      author_email='unitree@unitree.com', 

      # 可选参数: 从README.md读取的长描述，这将显示在PyPI上
      long_description=open('README.md').read(), 

       # 可选参数: 指定长描述的格式（本例为markdown）
      long_description_content_type="text/markdown",
      
      # 可选参数: 软件许可证标识（本例为BSD 3-Clause）'
      license="BSD-3-Clause", 
      
      # 可选参数: 包的简短描述
      description='Unitree robot sdk version 2 for python',  
      
      # 可选参数: 项目相关URL（通常是源代码、文档等）
      project_urls={
            "Source Code": "https://github.com/unitreerobotics/unitree_sdk2_python",
      },

      # 可选参数: 指定Python版本要求（>=3.8）
      python_requires='>=3.8', 

      install_requires=[
            "cyclonedds==0.10.2", # 指定DDS版本
            "numpy",
            "opencv-python",
      ],
      )

setup.py 是打包配置，不是 SDK 的控制逻辑。初学时从 example/ 找到一次具体调用，再进入 unitree_sdk2py/ 查找对应客户端与消息定义，能更清楚地理解接口。

如何选择下一步示例

先按机器人型号进入对应的 example 目录，阅读脚本依赖的客户端、消息类型和网卡参数。Go2 的避障、摄像头或运动示例不能据此推定同名功能也适用于 G1。

学习时可依次查看状态读取、消息字段、通信配置，再研究控制接口。Python SDK 本身不提供完整的导航感知系统：需要将传感器、定位、规划和控制分别接好，才能讨论自主避障。

安装依赖与设备支持范围以 unitree_sdk2_python README 为准。本文列出的 Python 3.8 与 Cyclone DDS 0.10.2 来自原笔记环境，不应视为所有新版本的通用要求。
