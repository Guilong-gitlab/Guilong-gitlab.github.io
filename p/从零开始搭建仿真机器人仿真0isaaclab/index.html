目前任务如何让机器人走起来以及后续机器的行走是与此相关的。

其实也得考虑一个问题，就是做机器人导航算法的很多，他们是如何让机器人走起来的呢？

如何搭建一个场景

想象你要拍摄一个机器人广告视频：

拍视频的步骤 代码对应的操作
架设摄像机 启动仿真应用（AppLauncher）
搭建摄影棚 创建仿真环境（SimulationContext）
铺地板 添加地面（GroundPlaneCfg）
打灯光 添加灯光（DomeLightCfg）
放道具（起点/终点标记） 添加标记方块（CuboidCfg）
请演员（机器人）进场 加载机器人（Articulation）
调整机位 设置相机视角（set_camera_view）
开始录制 进入仿真主循环（while…sim.step）

# g1_scene_demo_simple.py
import sys
sys.path.append("/home/guilong/Desktop/unitree/unitree_sim_isaaclab")

from isaaclab.app import AppLauncher
import argparse

parser = argparse.ArgumentParser()
AppLauncher.add_app_launcher_args(parser)
args_cli = parser.parse_args()
app_launcher = AppLauncher(args_cli)
simulation_app = app_launcher.app

import isaaclab.sim as sim_utils
from isaaclab.sim import SimulationContext
from isaaclab.assets import Articulation
from robots.unitree import G129_CFG_WITH_DEX1_WHOLEBODY

# 创建仿真
sim = SimulationContext()

# 添加地面
ground_cfg = sim_utils.GroundPlaneCfg()
ground_cfg.func("/World/Ground", ground_cfg)

# 添加简单的光源 - 只用 DomeLight
dome_cfg = sim_utils.DomeLightCfg(intensity=400.0)
dome_cfg.func("/World/DomeLight", dome_cfg)

# 添加标记点
start_cfg = sim_utils.CuboidCfg()
start_cfg.size = (0.4, 0.4, 0.05)
start_cfg.visual_material = sim_utils.PreviewSurfaceCfg(diffuse_color=(0.0, 1.0, 0.0))
start_cfg.func("/World/Start", start_cfg, translation=(0.0, 0.0, 0.025))

goal_cfg = sim_utils.CuboidCfg()
goal_cfg.size = (0.4, 0.4, 0.05)
goal_cfg.visual_material = sim_utils.PreviewSurfaceCfg(diffuse_color=(1.0, 1.0, 0.0))
goal_cfg.func("/World/Goal", goal_cfg, translation=(4.0, 3.0, 0.025))

# 配置机器人
G129_CFG_WITH_DEX1_WHOLEBODY.prim_path = "/World/G1"
robot = Articulation(cfg=G129_CFG_WITH_DEX1_WHOLEBODY)

# 相机
sim.set_camera_view(eye=(4.0, 4.0, 3.0), target=(0.0, 0.0, 0.8))

# 运行
sim.reset()
print("仿真运行中... 按 Ctrl+C 退出")
while simulation_app.is_running():
    sim.step()

simulation_app.close()

from isaaclab.app import AppLauncher
import argparse
parser = argparse.ArgumentParser()              # 创建参数容器
AppLauncher.add_app_launcher_args(parser)       # 往容器里装参数
args_cli = parser.parse_args()                  # 解析命令行输入
app_launcher = AppLauncher(args_cli)            # 用参数启动器
simulation_app = app_launcher.app               # 拿到应用对象

🔑 核心概念：这就像打开一个游戏，你可以通过命令行参数决定：

  • 是否全屏（--fullscreen）
  • 窗口多大（--width 1280）
  • 是否显示（--headless）
1
2
3

# 命令行示例
python 我的仿真.py --headless          # 不显示窗口（服务器运行）
python 我的仿真.py --width 1920        # 设置窗口宽度

AppLauncher 是 Isaac Lab 用来启动仿真应用程序的工具。它背后是 NVIDIA Omniverse Kit，这是一个复杂的图形引擎。 参数的作用：告诉 Omniverse Kit 如何启动：

  • 要不要显示窗口？
  • 窗口显示多大？
  • 渲染质量如何？
  • 网络端口是多少？

📋 完整参数列表（按类别分组） 一、窗口显示相关

参数 类型 默认值 说明 使用示例
--headless 标志 False 无头模式（不显示窗口，适合服务器运行） --headless
--window_width 整数 1280 窗口宽度（像素） --window_width 1920
--window_height 整数 720 窗口高度（像素） --window_height 1080
--fullscreen 标志 False 全屏模式 --fullscreen
--hidpi 标志 False 启用高DPI支持（Retina屏幕） --hidpi
二、渲染质量相关
参数 类型 默认值 说明 使用示例
--renderer 字符串 “RayTraced” 渲染器类型："RayTraced"（光线追踪）或 "Rasterized"（光栅化） --renderer Rasterized
--samples_per_pixel 整数 32 每像素采样数（越高画质越好，越卡） --samples_per_pixel 64
--max_ray_depth 整数 4 光线追踪最大反弹次数 --max_ray_depth 8
三、性能相关
参数 类型 默认值 说明 使用示例
--max_frames 整数 无限制 最多渲染多少帧后自动退出 --max_frames 1000
--fps_limit 整数 60 限制帧率上限 --fps_limit 30
四、调试相关
参数 类型 默认值 说明 使用示例
--verbose 标志 False 输出详细日志 --verbose
--debug 标志 False 启用调试模式 --debug
--log_level 字符串 “info” 日志级别："debug", "info", "warning", "error" --log_level debug
五、网络相关
参数 类型 默认值 说明 使用示例
--port 整数 8211 WebSocket 通信端口 --port 9000
--livestream 标志 False 启用实时流 --livestream

🤖 模块三：实体加载（机器人的特殊性）

机器人的加载不是三步模式，因为它更复杂：

1
2
3

# 机器人加载的两步模式
G129_CFG_WITH_DEX1_WHOLEBODY.prim_path = "/World/G1"  # 第1步：告诉机器人在哪
robot = Articulation(cfg=G129_CFG_WITH_DEX1_WHOLEBODY)  # 第2步：创建机器人

为什么不同？

对比项 简单物体（方块/灯光） 复杂物体（机器人）
数据结构 单个刚体 多个关节连接的刚体树
配置文件 几行代码 整个URDF文件
添加方式 cfg.func() Articulation(cfg=...)
后续操作 静态展示 需要控制关节运动
🔑 核心概念：Articulation = 关节体 = 多个刚体通过关节连接

2
3
4

      │           └── 左脚（固定关节）
      └── 右大腿
            └── ...

🎬 模块四：执行循环（让时间流动）

4.1 重置场景 

1

sim.reset()  # 回到初始状态

reset() 做了什么？

  • 时间归零（回到t=0时刻）
  • 机器人回到初始姿态
  • 清空所有速度、加速度

4.2 设置相机视角 

1

sim.set_camera_view(eye=(4.0, 4.0, 3.0), target=(0.0, 0.0, 0.8))

参数理解：

1
2
3
4

# eye = 相机位置（你在哪）
# target = 相机看向的点（你看哪）
# 数学理解：向量 target - eye 就是视线方向
视线方向 = (0-4, 0-4, 0.8-3) = (-4, -4, -2.2)

4.3 主循环（核心中的核心） 

1
2

while simulation_app.is_running():  # 只要窗口没关
    sim.step()                      # 往前走一小步

🔑 核心概念：仿真 = 时间离散化

1
2
3
4
5
6

# 现实世界（连续）
时间: 0s -----> 0.1s -----> 0.2s -----> ...
# 仿真世界（离散）
时间: step0 → step1 → step2 → step3 → ...
      ↑       ↑       ↑       ↑
    sim.step() 每秒60次
