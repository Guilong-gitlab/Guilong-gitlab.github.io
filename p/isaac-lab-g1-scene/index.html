Isaac Lab 入门：搭建 G1 基础场景

从应用启动、地面与灯光到机器人加载，解释一个 Isaac Lab 场景的构成。

2025-07-04
阅读时长: 12 分钟

环境与适用范围

本文示例用于理解场景构成，尚未接入行走策略。先按 Isaac Lab 安装文档 安装彼此兼容的 Isaac Sim、Isaac Lab 与 Python，再运行该版本自带的空场景示例。

记录 Isaac Sim、Isaac Lab 和宇树仓库的版本或提交号。文中的 G129_CFG_WITH_DEX1_WHOLEBODY 来自宇树仓库的特定配置；运行前确认当前版本仍提供这个名称及对应模型资产。若名称或模块目录变化，按该版本 README 调整，不能只修改 Python 导入语句来掩盖模型差异。

准备宇树支持文件

场景资产与强化学习训练是两项不同任务。以下仓库分别提供相关配置和训练工程。 本文统一把仓库放在 ~/workspaces 下：

mkdir -p ~/workspaces
cd ~/workspaces
git clone https://github.com/unitreerobotics/unitree_sim_isaaclab.git

需要进一步研究训练流程时，再获取强化学习仓库：

1

git clone https://github.com/unitreerobotics/unitree_rl_lab.git

加载机器人模型只建立了物理对象。稳定站立与行走还需要控制器或训练好的策略；导航算法通常输出期望速度，再由行走策略转换为关节控制。

如何搭建一个场景

想象你要拍摄一个机器人广告视频：

拍视频的步骤代码对应的操作
架设摄像机启动仿真应用（AppLauncher）
搭建摄影棚创建仿真环境（SimulationContext）
铺地板添加地面（GroundPlaneCfg）
打灯光添加灯光（DomeLightCfg）
放道具（起点/终点标记）添加标记方块（CuboidCfg）
请演员（机器人）进场加载机器人（Articulation）
调整机位设置相机视角（set_camera_view）
开始录制进入仿真主循环（while…sim.step）

# g1_scene_demo_simple.py
import sys
from pathlib import Path
sys.path.append(str(Path.home() / "workspaces/unitree_sim_isaaclab"))

from isaaclab.app import AppLauncher
import argparse

parser = argparse.ArgumentParser()
AppLauncher.add_app_launcher_args(parser)
args_cli = parser.parse_args()
app_launcher = AppLauncher(args_cli)
simulation_app = app_launcher.app

import isaaclab.sim as sim_utils
from isaaclab.sim import SimulationContext
from isaaclab.assets import Articulation
from robots.unitree import G129_CFG_WITH_DEX1_WHOLEBODY

# 创建仿真
sim = SimulationContext()

# 添加地面
ground_cfg = sim_utils.GroundPlaneCfg()
ground_cfg.func("/World/Ground", ground_cfg)

# 添加简单的光源 - 只用 DomeLight
dome_cfg = sim_utils.DomeLightCfg(intensity=400.0)
dome_cfg.func("/World/DomeLight", dome_cfg)

# 添加标记点
start_cfg = sim_utils.CuboidCfg()
start_cfg.size = (0.4, 0.4, 0.05)
start_cfg.visual_material = sim_utils.PreviewSurfaceCfg(diffuse_color=(0.0, 1.0, 0.0))
start_cfg.func("/World/Start", start_cfg, translation=(0.0, 0.0, 0.025))

goal_cfg = sim_utils.CuboidCfg()
goal_cfg.size = (0.4, 0.4, 0.05)
goal_cfg.visual_material = sim_utils.PreviewSurfaceCfg(diffuse_color=(1.0, 1.0, 0.0))
goal_cfg.func("/World/Goal", goal_cfg, translation=(4.0, 3.0, 0.025))

# 配置机器人
G129_CFG_WITH_DEX1_WHOLEBODY.prim_path = "/World/G1"
robot = Articulation(cfg=G129_CFG_WITH_DEX1_WHOLEBODY)

# 相机
sim.set_camera_view(eye=(4.0, 4.0, 3.0), target=(0.0, 0.0, 0.8))

# 运行
sim.reset()
print("仿真运行中... 按 Ctrl+C 退出")
while simulation_app.is_running():
    sim.step()

simulation_app.close()

模块三：实体加载（机器人的特殊性）

机器人的加载不是三步模式，因为它更复杂：

1
2
3

# 机器人加载的两步模式
G129_CFG_WITH_DEX1_WHOLEBODY.prim_path = "/World/G1"  # 第1步：告诉机器人在哪
robot = Articulation(cfg=G129_CFG_WITH_DEX1_WHOLEBODY)  # 第2步：创建机器人

为什么不同？

对比项简单物体（方块/灯光）复杂物体（机器人）
数据结构单个刚体多个关节连接的刚体树
配置文件几行代码整个URDF文件
添加方式cfg.func()Articulation(cfg=...)
后续操作静态展示需要控制关节运动
🔑 核心概念：Articulation = 关节体 = 多个刚体通过关节连接

模块四：执行循环（让时间流动）

4.1 重置场景

1

sim.reset()  # 初始化/重置仿真上下文

sim.reset() 用于初始化或重置仿真上下文。开始新一轮机器人实验时，还需要按资产 API 显式写回根状态和关节状态，并重置相应缓冲；它不等同于自动把每个物体恢复到自定义的初始姿态。

4.2 设置相机视角

1

sim.set_camera_view(eye=(4.0, 4.0, 3.0), target=(0.0, 0.0, 0.8))

参数理解：

1
2
3
4

# eye = 相机位置（你在哪）
# target = 相机看向的点（你看哪）
# 数学理解：向量 target - eye 就是视线方向
# 视线方向 = (0-4, 0-4, 0.8-3) = (-4, -4, -2.2)

4.3 主循环（核心中的核心）

1
2

while simulation_app.is_running():  # 只要窗口没关
    sim.step()                      # 往前走一小步

每次 sim.step() 推进仿真。物理步长、渲染频率和程序的实际运行速度是不同概念；设置 1/60 秒的物理步长，不保证每秒墙钟时间一定完成 60 步。

此处只有场景推进。接入机器人控制时，还需要按所用资产接口设置目标、写入仿真数据，并在步进后更新资产状态；传感器也需要实际创建和更新，单独调用 sim.step() 不会自动生成本文未配置的雷达或相机。

可以对照 Isaac Lab 关节资产教程 理解“写入控制 → 仿真步进 → 更新缓冲”的顺序。
