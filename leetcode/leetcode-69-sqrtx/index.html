LeetCode 69：x 的平方根

利用二分查找计算整数平方根，理解左右边界、分界点与 O(log x) 时间复杂度。

2026-10-06
阅读时长: 4 分钟

题目

给你一个非负整数 x，计算并返回 x 的算术平方根。由于返回类型是整数，只保留整数部分，小数部分直接舍去。不能使用 pow(x, 0.5)、x ** 0.5 等内置指数函数或运算符。

题目链接：LeetCode 69：x 的平方根

例如：

x = 4
√4 = 2
返回 2

x = 8
√8 ≈ 2.828
舍去小数部分，返回 2

class Solution:
    def mySqrt(self, x: int) -> int:
        left = 0
        right = x + 1
        while left < right - 1:
            mid = (left + right) // 2
            if mid * mid <= x:
                left = mid
            else:
                right = mid
        return left

这个答案是正确的，本质上是在使用二分查找寻找一个分界点。

以 x = 8 为例：

1
2
3
4
5

0² = 0  <= 8
1² = 1  <= 8
2² = 4  <= 8
3² = 9  > 8
4² = 16 > 8

可以把整数分成两部分：

1
2
3
4

平方 <= x             平方 > x
0  1  2    |    3  4  5 ...
           ↑
         分界点

题目真正要求的是：找到最大的整数 k，使得 k² <= x。 对于 x = 8，这个整数就是 2。

代码一开始：

1
2

left = 0
right = x + 1

这里的设计很重要。left 始终表示一个满足：

1

left² <= x

的位置，而 right 始终表示一个满足：

1

right² > x

的位置。

为什么 left = 0？因为题目规定 x >= 0，所以一定有：

1

0² = 0 <= x

为什么 right = x + 1 而不是 right = x？因为我们希望 right² > x 从一开始就成立。例如 x = 1 时，如果 right = 1，那么：

1

1² = 1

并不大于 x。但如果：

1

right = x + 1

那么 right = 2：

1

2² = 4 > 1

条件成立。对于 x = 0，right = 1，同样有 1² > 0。

接下来：

1

while left < right - 1:

等价于：

1

while right - left > 1:

意思是：只要 left 和 right 中间还有整数，就继续寻找。

例如：

1
2

left = 2
right = 5

中间还有 3、4，所以继续。如果：

1
2

left = 2
right = 3

中间已经没有整数。此时又一直保证：

1
2

left² <= x
right² > x

所以 left 一定就是平方不超过 x 的最大整数。

每轮计算：

1

mid = (left + right) // 2

如果：

1

mid * mid <= x

说明 mid 是合法的，但它不一定是最大的合法值，所以：

1

left = mid

继续向右找。如果：

1

mid * mid > x

说明 mid 太大，所以：

1

right = mid

继续向左找。

可以记成：

标准解法

你的写法本身已经可以作为标准二分解法：

class Solution:
    def mySqrt(self, x: int) -> int:
        left = 0
        right = x + 1
        while left < right - 1:
            mid = (left + right) // 2
            if mid * mid <= x:
                left = mid
            else:
                right = mid
        return left

它的核心是始终保持：

1
2

left² <= x
right² > x

最后让：

1

right = left + 1

于是：

1

left² <= x < right²

所以：

1

left = floor(√x)

floor 就是向下取整。例如：

1
2

√8 ≈ 2.828
floor(√8) = 2

正好符合题目舍去小数部分的要求。

class Solution:
    def mySqrt(self, x: int) -> int:
        left = 0
        right = x
        ans = 0
        while left <= right:
            mid = (left + right) // 2
            if mid * mid <= x:
                ans = mid
                left = mid + 1
            else:
                right = mid - 1
        return ans

这里 ans 保存"目前找到的最大的合法值"。如果 mid² <= x，先：

1

ans = mid

再：

1

left = mid + 1

继续向右寻找更大的合法值。如果 mid² > x，就：

1

right = mid - 1

向左寻找。

两种写法本质相同：

1
2
3
4
5
6
7

我的写法：
left 始终保存合法位置
最后 return left

常见写法：
ans 单独保存目前最大的合法位置
最后 return ans

你的写法少用了一个 ans 变量，而且逻辑完整，没有必要为了所谓"标准答案"强行修改。

复杂度

这道题的搜索范围大约是 0 到 x。每进行一次二分，搜索范围都会缩小一半：

1
2
3
4
5
6

x
→ x/2
→ x/4
→ x/8
→ ...
→ 1

假设执行 k 次以后只剩下 1：

1

x / 2^k = 1

所以：

1
2

x = 2^k
k = log₂x

因此：

1

时间复杂度：O(log x)

代码只使用 left、right、mid 等固定数量的变量，没有创建随着输入规模增长的列表或其他容器，所以：

1

空间复杂度：O(1)

两种二分写法的复杂度相同：

时间复杂度          O(log x)        O(log x)
空间复杂度          O(1)            O(1)

复盘

这道题我的答案是正确的。最重要的是理解：二分查找不一定非要在一个真实的有序数组中进行。只要搜索空间存在类似：

1
2
3
4

满足条件        不满足条件
k² <= x   |    k² > x
           ↑
         分界点

这样的单调分界，就可以使用二分查找。

以后看到：

1

求最大的 k，使某个条件成立

或者：

1

求最小的 k，使某个条件成立

并且条件随着 k 的变化呈现：

1

成立 成立 成立 | 不成立 不成立 不成立

这样的规律，就应该考虑"二分答案"。

left² <= x
right² > x

mid² <= x → left = mid
mid² > x  → right = mid

最后 left 和 right 相邻
→ left 就是平方不超过 x 的最大整数
→ return left
