Ubuntu 安装与机器人开发环境检查

从选择系统版本、制作启动盘到安装后的驱动和开发环境检查。

2025-02-26
阅读时长: 3 分钟

安装机器人开发环境前，先确定目标项目支持的 Ubuntu、ROS 和仿真器版本，再选择系统。不要仅按“最新版本”安装，也不要为了运行一个容器项目就直接重装宿主机。

1. 选择与项目匹配的系统

本网站中的两组常见环境是 Ubuntu 22.04 + ROS 2 Humble，以及 Ubuntu 24.04 + ROS 2 Jazzy。项目使用 Docker 时，要区分宿主机系统与容器内部系统：ROS 依赖通常安装在容器中，显卡驱动由宿主机提供。

查看 ROS 2 发行版说明 和目标项目 README，记录以下信息：

项目安装前需要确认
Ubuntu发行版、CPU 架构、启动方式
ROS发行版与系统是否匹配
仿真器支持的系统、驱动、Python 版本
GPU型号、显存与驱动要求
磁盘系统、模型、Docker 镜像和日志所需空间

ROS 1 老项目应按对应发行版说明复现，不能把 ROS 1 的安装命令直接套到 ROS 2 环境。

2. 准备安装介质

从 Ubuntu 下载页 获取所需版本的 ISO，并按下载页面提供的校验方法检查文件。准备可覆盖的 U 盘，使用启动盘制作工具将 ISO 写入 U 盘；直接把 ISO 文件复制进去通常不能启动。

安装前备份重要文件。双系统还应保存原系统的恢复信息，并先在原系统中为 Ubuntu 留出未分配空间。写启动盘时确认选中的确实是 U 盘。

3. 从 U 盘启动并试用

重启后进入电脑的启动菜单，选择 U 盘的 UEFI 启动项。不同品牌的按键不同，以设备说明为准。先进入试用环境，检查显示、键盘、网络和目标磁盘是否可识别，再启动安装程序。

选择语言、键盘、时区和账户。安装器的具体界面随版本变化，流程可对照 Ubuntu 官方安装教程。

4. 选择磁盘与分区

  • 独占整块磁盘：只在确认该盘内容可以清除时选择擦除磁盘安装。
  • 与现有系统共存：检查安装器给出的并存选项与分区预览，确认原系统分区被保留。
  • 手动分区：需要清楚识别目标磁盘、根分区和 EFI 系统分区；不要格式化其他系统已有的 EFI 分区。

在最终写入磁盘之前，逐项核对磁盘型号、容量、挂载点和格式化标记。安装完成后按提示重启并拔出启动盘，确认能进入系统；双系统还应测试原系统能否启动。

5. 更新与基础检查

进入 Ubuntu 后先完成网络连接和系统更新：

1
2
3

sudo apt update
sudo apt upgrade
sudo apt install git curl build-essential

重启后记录系统与磁盘信息：

1
2
3

lsb_release -a
uname -m
df -h

使用 NVIDIA 显卡时，可先在“软件和更新 → 附加驱动”中选择适合硬件的驱动，安装并重启后检查：

1

nvidia-smi

如果开启 Secure Boot，驱动安装过程中可能需要完成密钥注册。先解决宿主机驱动问题，再安装 Isaac Sim 或配置 Docker GPU。

6. 安装开发环境

按目标项目选择一条路线：

  1. 原生 ROS 2：使用对应发行版的官方安装步骤，然后在新终端加载 /opt/ros/发行版/setup.bash。
  2. Docker 项目：安装 Docker Engine、Compose 和所需 GPU 运行时，继续阅读 Docker 教程。
  3. Isaac Lab 项目：按 Isaac Lab 场景搭建 的环境说明检查 Isaac Sim、Isaac Lab 与 Python 的兼容关系。

每装好一层就运行一次最小示例，不要同时安装几套 ROS 后再统一排错。

7. 常见问题

现象先检查什么
启动菜单里没有 U 盘启动盘制作是否成功、UEFI 设置和 USB 接口
安装器看不到目标磁盘磁盘控制器设置与设备兼容性；先查设备文档
安装后黑屏能否进入恢复模式、显卡驱动是否与硬件匹配
nvidia-smi 失败驱动模块、Secure Boot 注册和重启是否完成
ros2 命令不存在ROS 是否安装、当前终端是否 source 正确发行版
仿真器报 Python 模块错误当前解释器是否来自项目指定环境

保存系统版本、驱动版本和项目提交号，后续遇到问题时即可判断是哪一层发生了变化。
