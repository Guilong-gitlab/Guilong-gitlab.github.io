VS Code 配置 XeLaTeX 与 Biber

配置中文论文编译流程，完成参考文献测试，并使用 LaTeX Workshop 清理辅助文件。

2025-04-10
阅读时长: 3 分钟

本文使用 TeX Live、VS Code 和 LaTeX Workshop，配置 XeLaTeX → Biber → XeLaTeX → XeLaTeX 编译流程，适合中文文档与 biblatex 参考文献。

1. 安装与检查

按 TeX Live 官方安装说明 安装发行版，再在 VS Code 扩展中安装 LaTeX Workshop。打开新终端检查：

1
2

xelatex --version
biber --version

两条命令都应能找到程序。安装后仍提示命令不存在时，检查 TeX Live 的可执行文件目录是否在 PATH 中，并重启 VS Code。发行版已安装但缺少宏包时，应通过该发行版的包管理方式补齐。

2. 配置编译步骤

打开项目文件夹，通过命令面板选择 Preferences: Open Workspace Settings (JSON)，在 .vscode/settings.json 中合并以下配置。若原文件已有内容，只添加字段，不要再套一层大括号。

{
  "latex-workshop.latex.tools": [
    {
      "name": "xelatex",
      "command": "xelatex",
      "args": ["-synctex=1", "-interaction=nonstopmode", "-file-line-error", "%DOC%"]
    },
    {
      "name": "biber",
      "command": "biber",
      "args": ["%DOCFILE%"]
    }
  ],
  "latex-workshop.latex.recipes": [
    {
      "name": "XeLaTeX → Biber → XeLaTeX × 2",
      "tools": ["xelatex", "biber", "xelatex", "xelatex"]
    }
  ],
  "latex-workshop.latex.autoBuild.run": "never"
}

先手动构建，确认流程正常后再考虑自动构建。这套配置让输出与根 .tex 文件位于同一目录；若改用其他输出目录，需要同步修改 XeLaTeX 和 Biber 的参数。

3. 创建最小测试工程

在同一个文件夹中建立 main.tex 与 ref.bib。

main.tex：

\documentclass[UTF8]{ctexart}
\usepackage{amsmath}
\usepackage[backend=biber,style=numeric]{biblatex}
\addbibresource{ref.bib}
\title{XeLaTeX 编译测试}
\author{测试作者}
\date{\today}

\begin{document}
\maketitle
中文正文与公式：\(E=mc^2\)。
参考文献引用示例：\cite{khasminskii2011stochastic}。
\printbibliography
\end{document}

ref.bib：

@book{khasminskii2011stochastic,
  title = {Stochastic Stability of Differential Equations},
  author = {Khasminskii, Rafail},
  year = {2011},
  publisher = {Springer}
}

4. 编译与验证

打开 main.tex，在命令面板运行 LaTeX Workshop: Build with recipe，选择上面定义的配方。也可以在文件所在目录依次执行：

1
2
3
4

xelatex main.tex
biber main
xelatex main.tex
xelatex main.tex

第一次 XeLaTeX 生成 Biber 需要的控制文件，Biber 读取 .bib 生成参考文献，后两次 XeLaTeX 更新引用与交叉引用。检查 main.pdf 中是否显示中文、文献编号和文末参考文献列表。

多文件论文应从根文件构建；子文件可以添加 % !TEX root = main.tex，路径按实际目录调整。模板如果使用 BibTeX 而不是 biblatex，应遵循模板流程，不能直接套用 Biber。

5. 清理辅助文件

在命令面板运行 LaTeX Workshop: Clean up auxiliary files。如需快捷键，可在 Preferences: Open Keyboard Shortcuts (JSON) 中添加：

1
2
3
4
5
6
7

[
  {
    "key": "ctrl+shift+delete",
    "command": "latex-workshop.clean",
    "when": "editorLangId == latex"
  }
]

该方式通过扩展清理辅助文件，不依赖当前终端是 PowerShell、Bash 还是 CMD。清理规则可以在扩展设置中调整。若需要 PDF 与源码双向跳转，保留 .synctex.gz；清理后也可以重新编译生成。

6. 常见错误

现象检查与处理
找不到 xelatex 或 biber检查 TeX Live 安装、PATH 和 VS Code 进程环境
找不到 ref.bib检查文件名、路径和根文件位置
引用显示为问号看 Biber 日志、引用键与编译顺序
Biber 找不到 .bcf确认第一次 XeLaTeX 成功，且使用了 biblatex
中文或字体报错检查 ctex 宏包和模板要求的字体
子文件单独编译失败为扩展指定正确的根文件

编译设置及占位符含义可查阅 LaTeX Workshop 编译文档。
