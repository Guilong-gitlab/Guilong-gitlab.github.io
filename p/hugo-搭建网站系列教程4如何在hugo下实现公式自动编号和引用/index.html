Hugo 搭建网站系列教程4：如何在hugo下实现公式自动编号和引用

在hugo中实现类似latex的公式引用方法，能够对行间公式自动编号和医用

2025-02-26
阅读时长: 3 分钟

下面是一份从零开始的完整示例，教你如何在 Hugo 中通过 MathJax 实现公式的自动编号和引用。之所以不用 KaTeX，是因为 KaTeX 默认没有“自动给所有行间公式编号”的功能；若要自动编号并且想用 \label、\ref 来引用，MathJax 更合适。

以下操作基于你已经装好 Hugo 并且在使用常见主题（比如我使用的就是 hugo-theme-stack）进行网站构建为前提。

第 1 步：禁用或移除主题自带的 KaTeX

大多数 Hugo 主题（例如 hugo-theme-stack）会在检测到 params.article.math = true 或在文章 Front Matter 里写了 math: true 时自动加载 KaTeX。为了让我们接下来放置的 MathJax 生效，需要先禁用这个自动加载。

如果你之前在 config.yaml（或 config.toml 等）里写了：

1
2
3

params:
  article:
    math: true  # 默认启用 KaTeX

请改成 false 或者干脆去掉这一行。例如：

1
2
3

params:
  article:
    math: false

或者删除这行，这样主题就不会再自动插入 KaTeX 相关脚本。

如果你的主题没有任何 KaTeX 配置，可直接略过本步。

第 2 步：创建一个自定义的部分模板，放入 MathJax 脚本

假设你想让 MathJax 在每个页面全局生效，你可以在 Hugo 站点根目录下（不是主题目录）的 layouts/partials/ 文件夹里新建一个文件，如 mathjax-support.html，其内容类似下面：

 1

<script>
    window.MathJax = {
      tex: {
        tags: 'ams',  // 启用自动编号 (AMS 环境)
        inlineMath: [['$', '$'], ['\\(', '\\)']],
        displayMath: [['$$','$$'], ['\\[','\\]']],
        packages: ['base', 'ams']
        // 允许使用 \label{eq1} / \ref{eq1} / \eqref{eq1} 来引用公式
      },
      options: {
        // 可根据需求，决定是否让 MathJax 遇到报错时仍然渲染其他部分
        // 或是否启用 menuOptions: {...}
      }
    };
    </script>

    <script defer src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-chtml.js"></script>
  • tags: ‘ams’ 让所有用 \begin{equation}...\end{equation} 包裹的块级公式自动产生连续编号。
  • 默认行内公式仍使用 $...$，块级公式使用 $$...$$。如果你想强制都用 \(...\) 和 \[...\]，只要修改 inlineMath 与 displayMath 里分隔符即可。

第 3 步：在 <head> 中引入这个部分模板

你需要把 mathjax-support.html 放到网页 <head> 里，让浏览器加载它。以 hugo-theme-stack 为例，你可以这样做：

  1. 在站点根目录下（或主题支持的 override 目录）找到/创建 layouts/partials/head.html。
  2. 在你希望插入 MathJax 的地方，添加： 
    1

    {{ partial "mathjax-support.html" . }}

大多数主题在 head.html 里会有一些公共的 <meta>、CSS 引用等内容，你只需要在适当的地方插入上面那行 partial 即可，示例如下：

 1
 2
 3

<!DOCTYPE html>
<html lang="{{ .Lang }}">
<head>
  <meta charset="UTF-8">
  ...
  {{ partial "mathjax-support.html" . }}
</head>
<body>
  ...
</body>
</html>

这样，每次渲染页面时，都会自动注入我们第 2 步写的 MathJax 配置和脚本。

第 4 步：编写带编号和引用的公式

完成以上三步后，你就可以在 Hugo 的 Markdown 文件中写出 LaTeX 环境来获得自动编号。通常推荐用 equation 环境，并配合 \label / \ref / \eqref 等。

4.1 自动编号

示例一：一个简单的自动编号方程

1
2
3

\begin{equation}
E = mc^2
\end{equation}

编译后会自动给这行方程打上一个编号，比如 “(1)”。后面写的会自动递增编号。

4.2 手动引用

如果想在文章中其他地方引用这个公式，可以给它加个 \label 标记：

1
2
3
4

\begin{equation}
E = mc^2
\label{eq:energy}
\end{equation}

然后在文字里写：

1

我们可以看到公式 (\ref{eq:energy}) 给出了质量和能量之间的关系。

MathJax 会把 (\ref{eq:energy}) 渲染成对应公式编号，比如 “(1)”，并且会在公式处加相应的内部跳转（如果主题或浏览器支持的话）。

也可以用 \eqref{eq:energy} 的方式引用，它会直接带上括号并形成链接。

补充：如何修改 文件

  1. 找到 layouts/partials/head/head.html

    • 进入你的 Hugo 项目目录： 
      1

      themes/hugo-theme-stack/layouts/partials/head/
    • 找到 head.html 文件。

  2. 复制到你的站点目录

    • 复制 themes/hugo-theme-stack/layouts/partials/head/head.html 到 Hugo 站点根目录下的 layouts/partials/head/ 目录： 
      1
2

      mkdir -p layouts/partials/head
cp themes/hugo-theme-stack/layouts/partials/head/head.html layouts/partials/head/head.html

  3. 编辑 layouts/partials/head/head.html

    • 打开 layouts/partials/head/head.html，在 </head> 之前插入： 
      1

      {{ partial "mathjax-support.html" . }}
